# Rumos da Liberdade — Projeto Escolar de Ciências Humanas

Site interativo (HTML, CSS e JavaScript puros) com uma história em quadrinhos de 6 páginas, um portal com as ideias e um vídeo explicativo.

Todos os arquivos ficam na mesma pasta (sem subpastas):

- `index.html`, `style.css`, `script.js` — o site
- `comic_page_01.png` a `comic_page_06.png`, `bandeira-brasil.png` — imagens
- `video-sobre-as-ideias.mp4`, `poster.jpg` — vídeo e capa

Para publicar: GitHub → Settings → Pages → branch `main`, pasta `/ (root)`.
